# 匿名使用统计

项目只记录以下四个汇总计数：

| 事件 | 计数规则 |
| --- | --- |
| `page_open` | 页面成功打开；同一浏览器标签页只计一次 |
| `weread_connected` | Skill Key 验证并连接成功；同一浏览器标签页只计一次 |
| `preview_generated` | 场景预览成功生成；同一次打开场景只计一次 |
| `image_downloaded` | JPG 文件成功准备并触发下载；每次成功下载计一次 |

## 查看统计

这些统计此前仅在本地，2026-11-03核查线上接口返回404，不能补算未采集的历史人数。新功能部署后请访问管理员页面，输入管理口令查看总数和每日明细：

```text
https://m8mi6m.top/analytics
```

底层JSON接口 `/api/analytics?days=30` 需要 `Authorization: Bearer <管理口令>`，`days` 可填写 `1` 至 `90`。次数不等于独立用户数。

## 隐私范围

应用的统计存储只包含日期、事件类型和累计数字，不写入微信读书 Skill Key、书籍数据、IP、Cookie 或用户标识。浏览器端只用 `sessionStorage` 保存当前标签页是否已经上报过页面打开与连接成功，不用于跨标签页或跨设备识别用户。

EdgeOne 平台自身仍可能按照平台规则保留基础请求日志；这些日志不由本项目的匿名统计代码写入 Blob。
