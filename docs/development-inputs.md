# 开发前需要你提供或确认的内容

这份清单用于避免开发中途卡住。现在的 MVP 可以先用 mock 数据跑起来；下面这些内容越早提供，后续越快接入真实服务。

## 必须提供

### 1. 微信读书 skillKey

用途：

- 测试连接设置页。
- 后续调用微信读书 skill 获取真实阅读数据。

现在状态：

- 可以先不提供，项目会用 mock 数据。
- 真正接微信读书数据时必须提供。

### 2. 微信读书 skill 调用规则

已查到官网/官方仓库公开规则：

```text
请求地址：https://i.weread.qq.com/api/agent/gateway
请求方法：POST
鉴权方式：Authorization: Bearer <WEREAD_API_KEY>
请求格式：JSON
skill_version：1.0.4
```

请求 body 顶层必须包含：

```json
{
  "api_name": "/_list",
  "skill_version": "1.0.4"
}
```

注意：业务参数直接放在 body 顶层，不要包在 `params` 里。

当前已接入的接口：

```text
/_list              测试 key 是否可用，并读取可用 API 列表
/readdata/detail    获取阅读数据，用于本月/年度阅读小票
/shelf/sync         获取书架数据，用于书架封面墙
```

仍需用你的真实 key 验证：

- `/readdata/detail` 的 `mode: "monthly"` 是否满足本月阅读小票。
- 年度阅读小票是否用 `mode: "yearly"`，或需要按官方返回字段再调整。
- 阅读日历所需的每日阅读数据字段是否完整。

现在状态：

- 代码已经按上述规则封装真实调用。
- 没保存 key 时仍使用 mock 数据。
- 保存 key 后，“测试连接”会调用 `/_list`。
- 生成壁纸时会优先调用 `/readdata/detail`，失败会在页面显示错误。
